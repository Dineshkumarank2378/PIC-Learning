# PIC16F877A Library

A custom library for the PIC16F877A microcontroller.

This repository is part of a personal effort to gain a deeper understanding of microcontrollers and embedded systems.

## About the Project

I am building an entire library from scratch.

### Objectives

* Learn register-level programming (bare-metal)
* Understanding how peripherals, registers, and hardware work
* Improve C programming skills and code optimization skills
* Learn practical driver implementation techniques

## Current Status
